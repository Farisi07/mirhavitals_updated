MIRHA VITALS HOME HEALTHCARE LLC - WEBSITE
==========================================

Open index.html to view the site. Upload the whole folder as-is to any
static host. No build step.

BEFORE PUBLISHING
-----------------
1. assets/js/data.js, block "SITE" (top of file): replace the demo values.
   licenceNo is "0000000" and the Instagram / LinkedIn links point to the
   home pages of those sites. Every page reads this block when it loads.
   The HTML files also carry the same values as a no-JavaScript fallback;
   a find-and-replace across the .html files for "0000000" keeps them in
   step.

2. Founder photo: assets/images/founder/founder-demo.jpg is a generated
   demo portrait, NOT Naina Javed. Replace it with her real photo (portrait,
   about 1000 x 1250) and either keep the same file name or change
   FOUNDER.photo in data.js.

3. Testimonials: the six cards are samples (TESTIMONIALS array in data.js,
   each marked demo: true, which shows the "Sample" chip). Replace the text,
   name and service with real client testimonials and set demo: false.

4. Demo copy: every element marked data-demo="true" (with the comment
   "DEMO COPY: replace" above it) was written as a stand-in. Search the
   .html files for data-demo to find them all. Text that came from the
   client's document carries no such mark.

5. Photographs: see the table below.
